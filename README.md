# VOSKYTT — V2 česky

Původní design V2 zůstal zachovaný. Změnily se pouze texty do češtiny, cena BADAMAN TEE na 799 Kč a obsah objednávkového formuláře.

## Nahrání na GitHub
1. Otevři repozitář webu.
2. Nahraj všechny soubory z této složky do kořenové složky repozitáře.
3. Potvrď nahrazení starých souborů a klikni na **Commit changes**.
4. Cloudflare Pages web automaticky nasadí.

## Objednávkový formulář
Po vyplnění formuláře se zákazníkovi otevře jeho e-mailová aplikace s předvyplněnou objednávkou na `voskytt@icloud.com`. Zákazník musí e-mail ještě odeslat.

## Produktové fotografie
Až budou fotografie hotové, placeholdery v `index.html` se nahradí obrázky. Design se kvůli tomu nemusí měnit.
